✈️ Trabajo Práctico Boostrap
Este repositorio contiene el código fuente de un trabajo práctico de desarrollo web. El proyecto es un sitio web interactivo, completamente responsive, diseñado para simular una plataforma de turismo y viajes.
🛠️ Tecnologías Utilizadas
HTML5 & CSS3: Estructura y estilos de la página.
Bootstrap: Sistema de grillas, componentes (Modales, Tooltips, Spinners, etc.) y diseño responsive.
jQuery / JavaScript: Manipulación del DOM, validaciones en tiempo real, animaciones y filtros dinámicos.
📑 Estructura del Proyecto y Funcionalidades
El sitio está dividido en 7 secciones principales, cada una aplicando diferentes técnicas y requerimientos del trabajo práctico:

1. 🏠 Home (Inicio)
Navbar Responsive: Menú de navegación principal con dropdown / mega menú adaptativo (Bootstrap).
Hero Section: Imagen o video de fondo con texto animado mediante jQuery.
Cards de Destinos: Tarjetas de presentación con efectos hover atractivos.
Contador Animado: Números dinámicos animados utilizando jQuery.
Carrusel de Testimonios: Slider interactivo con reseñas de usuarios.
Footer Completo: Contiene un formulario de suscripción/contacto, enlaces a redes sociales y un mapa embebido.
2. 🗺️ Destinos
Filtros Dinámicos: Sistema para filtrar destinos en tiempo real usando métodos de jQuery (.filter(), .hide(), .show()).
Grid Responsive: Diseño adaptativo que muestra 1, 2 o 3 columnas dependiendo del tamaño de la pantalla.
Efectos Visuales: Tarjetas (cards) con efectos de zoom (CSS + jQuery).
Tabla de Precios: Tabla responsiva usando la clase table-responsive.
3. 🏢 Agencias
Tarjetas Interactivas: Cards con efecto "Flip" implementado mediante CSS y jQuery toggle.
Sistema de Rating: Calificación con estrellas interactiva construida con jQuery.
4. 📬 Contacto
Formulario Validado: Validación de campos en tiempo real mediante eventos de jQuery (.on('input'), .val()).
Feedback Visual: Uso de spinner-border durante la "carga" del envío.
Modal de Confirmación: Ventana emergente (Bootstrap Modal) para confirmar el envío exitoso.
Diseño Responsive: Estructuración robusta utilizando Flexbox y el sistema de grillas de Bootstrap.
5. 💰 Precios
Tabla Comparativa: Desglose de planes y servicios.
Interactividad: Efectos hover dinámicos sobre las filas/columnas.
Tooltips: Información adicional desplegable al pasar el ratón, usando Bootstrap + jQuery.
6. 📰 Blog
Layout de Revista: Diseño maquetado al estilo editorial/magazine.
Filtro de Categorías: Filtrado de artículos mediante jQuery.
Comentarios: Sistema de comentarios simulados en las entradas del blog.
Scroll Animations: Elementos que se revelan o animan a medida que el usuario hace scroll en la página.
7. 🛡️ Módulo Educativo: Phishing
Sección especial dedicada a la concientización sobre ataques de Phishing.
